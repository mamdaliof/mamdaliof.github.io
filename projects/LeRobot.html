LeRobot SmolVLA Intent-Conditioned Manipulation

Two-Stage Intent Classification (BERT F1 85%), SO-101 Robot Arm Manipulation and Hugging Face Dataset

Project Overview

Vision-Language-Action (VLA) models enable robots to follow human instructions. This project addresses prompt ambiguity and policy stability on the SO-101 robotic arm using a two-stage intent pipeline and Hugging Face's LeRobot framework.

SO-101 Robot Arm BERT Intent Classifier 170-Episode Dataset Hugging Face LeRobot

The Challenge

End-to-end VLA models often struggle when user instructions are phrased in informal or ambiguous ways. Training large monolithic models directly on diverse natural language requires huge datasets and frequently leads to incorrect grasping motions.

The Engineering Solution

I engineered a decoupled, reliable architecture:

  • Two-Stage Intent Disambiguation: Built a fine-tuned BERT intent classifier that parses unstructured user text, extracts goal parameters, and resolves ambiguity before the policy executes.
  • 170-Episode Teleoperated Dataset: Collected and formatted a multimodal dataset of physical manipulation demonstrations on the SO-101 arm following Hugging Face LeRobot standards.
  • Action Chunking with Transformers (ACT): Deployed flow-based action prediction for smooth pick-and-place trajectories.
