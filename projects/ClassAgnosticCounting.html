Class-Agnostic Counting & MoCA Vision Screening

2D Gaussian Splatting Density Modeling and DINOv2 Parameter-Efficient Adaptation

Project Overview

This research explores foundational vision adaptation across two tasks: Class-Agnostic Counting (CAC), which estimates counts of novel object categories using few visual exemplars, and Montreal Cognitive Assessment (MoCA) Screening, which analyzes hand-drawn clock tests for automated cognitive impairment detection.

2D Gaussian Splatting DINOv2 Prompt Tuning CARPK MAE 14.91 Clinical MoCA Screening

The Challenge

Standard density-map counting models fail when object scales or categories change (for instance, counting microscopic cells versus vehicles). In cognitive screening, patient drawings have wide stylistic variations that confuse rigid rule-based systems, while training data is scarce.

The Engineering Solution

I engineered density representation and prompt-tuning architectures:

  • 2D Gaussian Splatting for Counting: Replaced static isotropic Gaussian kernels with learnable 2D anisotropic Gaussian splats, capturing directional object orientations and reducing CARPK Mean Absolute Error (MAE) from 23.40 down to 14.91.
  • DINO Channel Bypass: Passed exemplar query tokens directly into intermediate attention layers without altering pretrained backbone features.
  • Prompt-Tuned DINOv2 for MoCA: Fine-tuned soft prefix visual prompts on frozen DINOv2 encoders to evaluate drawing distortion markers with high diagnostic reliability.
