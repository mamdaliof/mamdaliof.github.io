RELBot Autonomous Mobile Robot Tracking

Real-Time Xenomai 4 / EVL Control Loop (1 ms), ROS2 Bridge, Edge YOLO and Monocular Depth Tracking

Project Overview

The RELBot is a differential-drive mobile robot built at the University of Twente (Robotics and Mechatronics Lab). The project combines computer vision (YOLO object detection and monocular depth estimation) with strict, microsecond-level motor control on an embedded Raspberry Pi 4.

Raspberry Pi 4 Xenomai 4 / EVL RTOS ROS2 Humble + XRF2 Edge YOLO + MiDaS Depth

The Challenge

Standard Linux kernels have timing variations of 10 to 15 ms due to general process scheduling. While unnoticeable on desktops, this jitter makes motor control erratic and unstable in dynamic mobile robots. Additionally, dedicated stereo cameras or LiDAR units add weight and power draw on lightweight platforms.

The Engineering Solution

I engineered a dual-layer cyber-physical system:

  • Real-Time Motor Control: Isolated CPU Core 1 on the Raspberry Pi 4 for a Xenomai 4 / EVL real-time kernel, running a 1 kHz PID motion control loop with under 15 microseconds of timing jitter.
  • Edge AI Perception: Deployed lightweight YOLO on the remaining CPU cores to detect target persons, paired with Single Image Depth Estimation (MiDaS) to estimate distance using a standard monocular camera.
  • Lockless XRF2 Bridge: Connected ROS2 navigation topics directly to the real-time motor controller via lockless shared-memory buffers.
