JIWY Embedded Vision & 2-Axis Servo Tracker

Altera DE10-Nano FPGA and ARM Co-Design, Real-Time 3D LUT Color Segmentation, and 100 Hz PID Control

Project Overview

The JIWY Embedded Tracker is a pan-tilt robotic vision platform developed at the University of Twente (Robotics and Mechatronics Lab). It demonstrates low-level embedded software engineering, custom memory-mapped I/O, and hardware/software co-design to track moving targets with minimal latency.

Altera DE10-Nano FPGA ARM Cortex-A9 Core 100 Hz PID Servo Loop Embedded C++ / Linux

The Challenge

Standard image segmentation in RGB color space is computationally heavy and sensitive to changing lighting. Running complex vision models on low-power embedded processors often causes frame drops and sluggish servo response.

The Engineering Solution

I engineered an optimized embedded vision and motion control pipeline:

  • 3D Look-Up Table (LUT) Segmentation: Built a pre-computed 3D indexing table in YUV color space, processing camera frames in just 12.05 ms with direct bounding-box centroid extraction.
  • FPGA and ARM Co-Design: Connected the Linux userspace application to FPGA fabric registers via memory-mapped /dev/mem interfaces, controlling a hardware-enforced 20 kHz PWM driver.
  • 100 Hz PID Control with Hardware Safety: Tuned digital PID controllers with software angle limits and hardware watchdog monitors to prevent mechanical overshoot.
